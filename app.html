🏁 Guide d'utilisation du Quiz
Bienvenue sur l'espace d'assistance. Voici comment profiter pleinement de votre expérience interactive sur les richesses du Cameroun.



1. Comment participer ?

Le quiz se présente sous forme de discussion instantanée (Chatbot).
Lancement : Tapez simplement "Prêt" dans la zone de saisie pour recevoir la première question.
Réponses : Écrivez votre réponse et cliquez sur le bouton "Envoyer" (ou appuyez sur Entrée).
Validation : Le système analyse votre réponse. Si elle est correcte, un message de succès s'affiche. Sinon, la correction vous est donnée pour vous aider à apprendre.
2. Le système de progression
Le parcours est divisé en 50 étapes réparties sur quatre thématiques :
Accueil (Généralités sur le territoire)
Culture (Traditions, langues et symboles)
Tourisme (Économie et sites majeurs)
Régions (Administration et chefs-lieux)
Note sur les pauses : Toutes les 10 questions, le bot marquera un arrêt. Il suffit de répondre "Oui" pour reprendre la suite du voyage.
3. Conseils pour réussir
Précision : Soyez précis dans les noms de villes ou de lieux.
Majuscules : Ne vous inquiétez pas pour les majuscules, le système les gère automatiquement !
Orthographe : Veillez à bien orthographier les noms propres pour que le bot puisse valider votre point.
4. Résultat final À la fin de la 50ème question, une analyse complète de vos performances sera effectuée. Vous recevrez :
Votre score total (nombre de bonnes réponses).
Votre taux de connaissance du Cameroun exprimé en pourcentage.
